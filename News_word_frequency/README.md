# News Word Frequency Outputs

For top words before 1%/3% upward and downward movements, see
[movement_groups/README.md](movement_groups/README.md) and open
[movement_groups/report.html](movement_groups/report.html).
Run `.venv/bin/python News_word_frequency/group_word_frequency.py` from the repository root.

Generated by `word_frequency.py` from `news data pull/processed/all_classified_articles.csv`.

## Files

- `overall_word_frequency.csv`: one row per unique word across the 9,740 retained `direct` and `indirect` articles.
- `daily_word_frequency.csv`: one row per word per UTC publication date, preserving the New York publication date and same-date NVDA movement context.

## Counting rules

- Corpus: articles classified `direct` or `indirect`.
- Text: headline plus summary.
- Normalization: lowercase and simple alphanumeric tokenization.
- No stopword removal, stemming, lemmatization, sentiment scoring, or causal inference.
- `total_occurrences` / `word_occurrences` count every token occurrence.
- `article_count` / `articles_containing_word` count distinct articles containing the word.
- Dates are retained as both UTC and America/New_York calendar dates.

The stock movement columns in the daily file are same-date context only. They do not show that a word caused or affected the market. For causal or predictive timing analysis, join the word records to `data/matched/2025-09-15_2026-05-15/event_article_matches.csv` using the article identity and the documented prior-session cutoff.

## Local Matplotlib plots

Install the plotting dependencies and run:

```bash
python3 -m pip install -r News_word_frequency/requirements.txt
python3 News_word_frequency/plot_word_frequency_matplotlib.py
```

The script creates `matplotlib_plots/layered_frequency_and_return.png`, which overlays word frequency and next-session NVDA return on the same date axis using two y-axes, and `matplotlib_plots/word_frequency_return_scatter.png`, which shows correlation-style scatterplots and fitted lines for selected words. The fitted lines are exploratory and do not establish causality.
