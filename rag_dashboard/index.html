How Sentry News works

Local research
01 / NEWS

Start with a source.

We read the saved news archive and show the original headline, summary and publisher.

02 / INPUT

A small snapshot.

Qwen receives the first article matching your filters and the simulated portfolio weights attached to it. It does not see the full day's news.

03 / ANALYSIS

Understand the reasoning.

The local Qwen script asks for suggested weights and an explanation for each asset. Results are checked for basic allocation and citation issues.

04 / CONTEXT

Know the limits.

These are illustrative, news-based suggestions. The data has no returns or covariance estimates, and historical availability has not been verified. This is not investment advice.
